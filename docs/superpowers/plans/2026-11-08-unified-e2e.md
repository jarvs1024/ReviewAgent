# 统一 E2E + 配置生效性 实施计划

**Spec**：`docs/superpowers/specs/2026-11-08-unified-e2e-design.md`（commit `ee4c846`）
**分支**：`new_review_v2`（不合并 main）

## T1 配置校验（review.yaml 嵌套 + env 遮蔽）

- 文件：`reviewagent/scenario/profile.py`、`tests/test_review_config_validation.py`
- 从 `_apply_config` 的 mapping 自动派生嵌套白名单；分组必须为 mapping；
  未知嵌套 key 抛 `ValueError`（消息含完整路径与允许键列表）。
- env 覆盖 `review.yaml` 且值不同 → `logger.warning("config.env_shadowed ...")`。
- 测试：`limits.max_suggestion` 失败、`limits: 5` 失败、合法键通过、无告警；

## T2 开放 repo_context / reporting 用户组

- `_ALLOWED_REVIEW_CONFIG_KEYS` += `repo_context`, `reporting`；
  `reporting` 只允许 `weekly_title` / `repo_scan_extensions` / `repo_scan_entry_files`，
  `actions_file` 保持场景包专属（路径越界风险）。
- 测试：两组键生效并入 fingerprint；`actions_file` 报未知键。

## T3 接线失效配置

- `review_config_dir`：`_resolve_config_dir` 读 `current().review_config_dir`。
- `weekly_timezone`：`reporting/runner.py` 用 `ZoneInfo(cfg.timezone)`，非法值
  在周报启动时 ValueError。
- `weekly_cron_schedule`：`scripts/services_ops.sh` start/restart 时按 env 渲染
  `reviewagent-weekly.timer.d/schedule.conf`（仅 root + systemd 环境）。
- 测试：`tests/test_scenario_wiring.py`。

## T4 witness 目录 + 快速档

- `scripts/e2e/catalog.py`：`CATALOG`（field → kind/evidence/check）、
  `BEHAVIOR_WITNESSES`（id → callable）。
- `tests/test_config_catalog.py`：并集 == SCHEMA；behavior id 可实现；
  约束字段非法值启动失败（parametric）。
- `tests/test_config_effectiveness.py`：L2 witness（建议条数/严重度/评分/抽样/
  文件上限/分批/上下文行数/优先级/路径过滤/规则禁用覆盖提升/动态参数/repo_context）。

## T5 E2E harness 重构

- `scripts/e2e/{stack,fixtures,flows,report,config_audit,run_e2e}.py`；
  `verify_e2e.py` → shim。
- `run_e2e.py --tier fast|full`，`--round`、`--keep`、`--only`。
- 锁策略：仅启动时清 cooldown/max_calls/diff_head；不删 `reviewagent:lock:*`。

## T6 真实数据全量跑通

- fixture：临时项目 + `main` 基线 + 变更分支（wildcard import / 跨文件引用 /
  低价值 nit / conftest.py / testcase 文件）。
- 断言：8 功能 + 配置可观测（条数 ≤ `max_suggestions`、无 low、conftest 无评论、
  规则键命中、动态证据存在）。
- 清理：删除项目/分支，输出 `logs/e2e/report-*.json`。

## T7 收尾

- 全量 `pytest`、`config check`、`run_e2e.py --tier full`；
- 更新 `config/README.md`、`docs/CONFIG.md`、`CHANGELOG.md`；
- 提交并 push `github/new_review_v2`。
